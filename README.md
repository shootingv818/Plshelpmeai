# اسکنر هوشمند آیوا (IVA Smart Scanner)

ربات تلگرامی برای اسکن هوشمند کارت بانکی با استفاده از API آیوا.

## ویژگی‌ها

- **اسکن هوشمند 3 فازی**: به جای 4,752,000 تست، فقط ~10,000 تست
  - فاز 1: پیدا کردن تاریخ انقضا (60 تست)
  - فاز 2: پیدا کردن CVV2 (9,900 تست)
  - فاز 3: پیدا کردن PIN (8 تست)
- **پنل تلگرامی کامل**: مدیریت همه چیز از طریق ربات
- **سیستم ورکر توزیع‌شده**: پخش کار روی چندین سرور
- **لاگ‌گیری پیشرفته**: ثبت و نمایش همه رویدادها
- **چرخش اکانت خودکار**: تعویض اکانت هنگام محدودیت

## معماری

```
iva-scanner/
├── core/           # هسته (رمزنگاری، احراز هویت، اسکنر)
├── bot/            # ربات تلگرام (Telethon)
│   └── panels/     # پنل‌های مدیریتی
├── worker/         # سرور ورکر (FastAPI)
├── config.py       # تنظیمات
├── db.py           # دیتابیس SQLite
└── run.py          # نقطه ورود
```

## نصب و راه‌اندازی

```bash
# نصب وابستگی‌ها
pip install -r requirements.txt

# کپی و تنظیم فایل env
cp .env.example .env
nano .env

# اجرا (حالت مستر - ربات تلگرام)
python run.py

# اجرا (حالت ورکر - سرور API)
MODE=worker python run.py
```

## تنظیمات ضروری

1. `API_ID` و `API_HASH`: از [my.telegram.org](https://my.telegram.org)
2. `BOT_TOKEN`: از [@BotFather](https://t.me/BotFather)
3. `OWNER_ID`: آیدی عددی تلگرام شما
4. `WORKER_SECRET`: کلید Fernet (اختیاری، برای رمزنگاری)

## نحوه کار اسکن

1. اکانت آیوا اضافه کنید (شماره + کد تایید)
2. شماره کارت 16 رقمی وارد کنید
3. ربات به صورت خودکار 3 فاز اسکن را اجرا می‌کند
4. نتیجه به صورت زنده نمایش داده می‌شود
